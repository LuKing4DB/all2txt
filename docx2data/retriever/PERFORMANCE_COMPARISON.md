## 四、问题诊断

### 4.1 索引搜索逻辑问题

**当前实现**：
```python
def search(self, query: str) -> List[str]:
    query_words = self._extract_keywords(query)
    # 统计每个文件的匹配度（命中关键词数）
    file_scores: Dict[str, int] = {}
    for word in query_words:
        if word in self.index:
            for doc_info in self.index[word]:
                file_path = doc_info['file_path']
                file_scores[file_path] = file_scores.get(file_path, 0) + 1
    # 按匹配度排序
    candidate_files = sorted(file_scores.items(), key=lambda x: x[1], reverse=True)
    return [file_path for file_path, score in candidate_files]
```

**问题**：
- 如果查询关键词在索引中不存在，`file_scores` 为空
- 返回空列表，导致回退到全量搜索

**解决方案**：
1. 改进关键词提取：确保查询关键词能匹配索引中的关键词
2. 模糊匹配：如果精确匹配失败，尝试部分匹配
3. 调试日志：添加索引搜索的详细日志
