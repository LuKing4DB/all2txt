## 四、问题诊断

### 4.1 索引未构建的原因

**可能原因**：
1. `DocumentRetriever` 初始化时没有调用 `build_index()`
2. 索引缓存文件不存在或为空
3. 索引构建失败但没有报错

**检查方法**：
```python
# 查看索引统计
stats = retriever.get_cache_stats()
print(stats)
# 如果 index 为空或 keywords=0，说明索引未构建
```

### 4.2 解决方案

**方案1：首次启动时自动构建索引**
```python
# 在 AntiRAGRetriever.__init__ 中
self.document_retriever = DocumentRetriever(data_dir=data_dir)
# 检查索引是否存在，如果不存在则构建
if self.document_retriever.searcher.index:
    stats = self.document_retriever.get_cache_stats()
    if stats.get('index', {}).get('keywords', 0) == 0:
        logger.info("索引为空，开始构建索引...")
        self.document_retriever.build_index()
```

**方案2：提供独立的索引构建脚本**
```python
# build_index.py
from retriever.lib.document_retriever import DocumentRetriever
retriever = DocumentRetriever(data_dir="data")
retriever.build_index()
```
