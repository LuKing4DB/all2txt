# 文本分割工具

使用正则表达式分割TXT文件的工具，支持按行匹配和全文匹配两种模式。

## 功能特性

- **正则表达式分割**：使用正则表达式匹配分割点
- **按行匹配模式**：默认按行匹配，`^` 匹配每行开头
- **全文匹配模式**：可选全文匹配模式
- **序号校验**：自动验证匹配的序号是否按顺序递增
- **目录过滤**：自动跳过目录区域
- **有序列表过滤**：自动跳过有序列表区域
- **递归深度**：支持设置递归深度（暂未实现递归逻辑）

## 安装依赖

```bash
pip install -r requirements.txt
```

主要依赖：
- Python标准库（`re`, `pathlib`等）

## 使用方法

### 基本用法

```bash
python src/split/main.py <文件路径> -p <正则表达式>
```

### 指定输出目录

```bash
python src/split/main.py <文件路径> -p <正则表达式> -o <输出目录>
```

### 禁用序号校验

```bash
python src/split/main.py <文件路径> -p <正则表达式> -n
```

### 使用全文匹配模式

```bash
python src/split/main.py <文件路径> -p <正则表达式> --no-line-mode
```

### 示例

#### Linux/Mac/Cmd

```bash
# 按章节分割（使用双引号，需要转义）
python src/split/main.py data/1/sub/1.txt -p "^第([一二三四五六七八九十\\d]+)章"

# 按数字标题分割
python src/split/main.py data/1/sub/1.txt -p "^\\d+\\.招标" -o output
```

#### PowerShell（推荐使用单引号）

```bash
# 按章节分割
python src/split/main.py data/1/sub/1.txt -p '^第([一二三四五六七八九十\d]+)章'

# 按数字标题分割
python src/split/main.py data/1/sub/1.txt -p '^\d+\.招标' -o output

# 使用双引号时，\d 在字符类中建议改为 0-9
python src/split/main.py data/1/sub/1.txt -p "^第([一二三四五六七八九十0-9]+)章"
```

#### 禁用序号校验

```bash
python src/split/main.py data/1/sub/1.txt -p "^\\d+\\.(?!\\d)" -n
```

## 输出文件

脚本会在输出目录生成分割后的文件：

- **`0.txt`** - 第一个分割段（第一个匹配之前的内容）
- **`1.txt`** - 第二个分割段（第一个匹配到第二个匹配之间的内容）
- **`2.txt`** - 第三个分割段
- ...

### 输出示例

```
data/1/sub/
├── 1.txt
└── 1_split/
    ├── 0.txt
    ├── 1.txt
    ├── 2.txt
    └── ...
```

## 功能说明

### 按行匹配模式（默认）

- 使用 `re.MULTILINE` 标志
- `^` 匹配每行的开头
- 自动跳过目录区域和有序列表区域
- 适合匹配行首的标题、章节等

### 全文匹配模式

- 在整个文件内容中匹配
- 适合匹配跨行的模式

### 序号校验

默认启用序号校验，会验证匹配的序号是否按顺序递增：
- 如果序号不连续，会跳过该匹配
- 如果序号重复，会选择文本较短的行
- 使用 `-n` 或 `--no-validate` 可以禁用校验

### 目录和列表过滤

脚本会自动检测并跳过：
- **目录区域**：连续多行的目录行（末尾是页码）
- **有序列表区域**：连续多行的有序列表（如 1. 2. 3. 等）

## 常用正则表达式示例

### 匹配章节标题

```bash
# 中文章节
'^第([一二三四五六七八九十\d]+)章'

# 数字章节
'^第\d+章'
```

### 匹配数字标题

```bash
# 1. 2. 3. 格式
'^\d+\.'

# 1) 2) 3) 格式
'^\d+\)'
```

### 匹配特定关键词

```bash
# 以"招标"开头的行
'^招标'

# 以数字+点+关键词开头的行
'^\d+\.招标'
```

## 命令行参数

- `file_path` - 输入文件路径（必需）
- `-p, --pattern` - 正则表达式模式，用于匹配分割点（必需）
- `-o, --output` - 输出目录（可选，默认在输入文件同级目录下创建 `文件名_split` 文件夹）
- `--no-line-mode` - 禁用按行匹配模式，改为全文匹配模式（默认是按行匹配）
- `-n, --no-validate` - 禁用序号自增校验（默认启用）

## 注意事项

- 正则表达式需要根据实际文档格式调整
- 建议先使用小文件测试正则表达式
- 序号校验可以帮助过滤误匹配，但可能也会过滤掉合法的非连续序号
- 目录和列表过滤可以提高分割准确性
